# Dlss5ForWOW

Это ответвление исходного проекта [DLSS 5 Sidecar for World of Warcraft](https://github.com/xilla420/dlss5-wow-sidecar). Инструкции для этого ответвления: [README](README.md). Историческая русская документация исходного проекта доступна [в оригинальном репозитории](https://github.com/xilla420/dlss5-wow-sidecar/blob/main/README.ru.md).

RTX 20: экспериментальная поддержка, не проверенная на оборудовании. Дистрибутив не содержит библиотеки NVIDIA; `nvngx_dlssnr.dll` необходимо предоставить самостоятельно.
